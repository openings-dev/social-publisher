## Preparation and selection

The user approved both excerpts. Each uses the first 9 seconds of the source,
normalized with `loudnorm=I=-18:TP=-1.5:LRA=7`, a 150 ms fade-in and a 700 ms
fade-out starting at 8.3 seconds. Encoding: 48 kHz stereo MP3, 192 kbps.
These exact mastered files are bundled and hash-checked; there is no runtime
download, subscription, registration or royalty payment.

The persisted artwork cycle selects Funked Up for Night and Funky House for
Paper/Lavender/Peach, producing A/B/A/B/A/B for newly selected jobs. Retries keep
their artwork and music. Story reuses the same verified Reel video. Delivery
order can differ if a provider is delayed. Historical v3 posters retain the old
audio; completed posts are not republished by this change.

Keep this directory and `soundtrack.mjs` byte-identical in web-deploy's
`scripts/social-artwork/` copy. Release web-deploy before social-publisher.
